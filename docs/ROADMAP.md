# Дорожная карта GoidaLang

## ✅ v0.1 (готово)

* Лексер/парсер с русским синтаксисом и алиасами, UTF-8.
* Комилятор AST → байткод, стековая ВМ, замыкания/upvalue.
* Mark-&-sweep GC с финализаторами нативных объектов.
* Типы: пусто/лог/целое/дробное/строка/массив/словарь/функции/натив-объекты.
* Операторы: пускай/постоянно, если/иначе, пока, для (C-style и foreach),
  цикл, прерви/продолжи, верни, составные `+=` и т.п.
* Менеджер модулей: встроенные + `.goida`-файлы + `$GOIDA_PATH`, кеширование.
* Стандартка: ядро + математика, строки, массивы, файлы, время, система,
  случай.
* Сокеты: TCP сервер/клиент, UDP; POSIX + winsock-ветка.
* REPL, стектрейсы ошибок, значения по умолчанию параметров.
* Тест-сьют (12 кейсов + TCP/UDP), примеры.

## 🔜 v0.2 — «выразительность»

1. **Строковая интерполяция** `"привет, {имя}!"` (лексер-шаблоны).
2. **Исключения**: `попытка { } лови (e) { } наконец { }`, `брось "текст"`;
   runtime-ошибки как значения; стектрейс в `e.трасса`.
3. **Классы (лёгкие)**: `класс Имя { дело метод(...) }` — словари с
   прототипом + `я` как явный self, `новый Имя(...)`.
4. **Множественный возврат** `верни a, b` → кортеж-массив + распаковка
   `пускай a, b = f()`.
5. **Оператор выбора** `выбери (x) { вариант 1: ... иначе: ... }`.
6. **Срезы** `a[1:3]`, `s[0:5]`, шаг `a[::2]`.
7. **Тернарник** `x если cond иначе y`.
8. Константы по-настоящему неизменяемые (флаг у слота/глобала).

## 🔜 v0.3 — «стандартка+»

1. Модуль `"json"`: `разбери(строка)`, `собери(значение)`.
2. Модуль `"регулярки"` (собственный мини-PCRE или POSIX regex).
3. Модуль `"http"`: клиент `http.получи(url)` поверх сокетов
   (HTTP/1.1, keep-alive не обязателен).
4. Модуль `"поток"`: зелёные потоки ВМ (кооперативные корутины:
   `породи`, `дай_другому`).
5. `"файлы"`: каталоги (`список_каталога`, `создай_каталог`, `удали`).
6. `"время"`: форматирование `формат_даты`, таймеры-колбэки.
7. Большая математика: `bigint` (целые произвольной точности, `целое_большое`).
8. Сериализация значений `repr`/`выражение()` (обратимый дамп).

## 🔜 v0.4 — «инструменты»

1. **Дизассемблер** `./goida --дампер файл.goida` (уже есть имена опкодов).
2. **Отладчик**: шаги, точки останова по строкам (`--отладка`).
3. **Профайлер** по строкам (счётчики на инструкцию).
4. Строгие предупреждения компилятора: неиспользуемые переменные,
   тенирование, недостижимый код (`--строгий`).
5. Форматтер исходников `goida --красиво`.
6. Пакетный менеджер: `goida пакет добавить <git-url>` в `$GOIDA_PATH`.

## 🎯 v1.0 — «скорость и платформы»

1. **Байткод-файлы** `.goidc`: прекомпиляция, заголовок версии.
2. Оптимизации: constant folding, peephole (CONST+CONST → CONST и т.п.),
   инлайнинг мелких дел.
3. Интернация строк для ускорения полей/глобалов.
4. Windows: CI-сборка winsock-ветки (mingw), проверка winsock в тестах.
5. Порт на другие libc (musl), статическая сборка.
6. Спецификация стабилизируется; семантика self/arity фиксируется как часть
   языка (или заменяется явными классами из v0.2).

## Идеи «когда-нибудь»

* `goida --веб` — встроенный HTTP-сервер приложений (мемный фреймворк
  «самовар»).
* WASM-бэкенд (через Emscripten) — гойда в браузере.
* LSP-сервер для подсветки/автодополнения в редакторах.
* Интернационализация сообщений об ошибках (`--язык=ен`).
