# Спецификация GoidaLang 0.1.0

## 1. Лексика

* Кодировка — UTF-8. Идентификаторы — буквы (включая кириллицу), `_`, цифры (не первым).
* Комментарии: `# ...`, `// ...`, `/* ... */`.
* Литералы: целые `42`, `0x2A`, дробные `3.14`, `1e3`, строки `"..."` с
  экранированием `\n \t \r \0 \\ \" \xNN`.
* Ключевые слова и алиасы:

| назначение | слова |
|---|---|
| переменная | `пускай`, `пусть`, `перем` |
| константа | `постоянно` |
| функция | `дело`, `функция` |
| если | `если`, `иначе` |
| циклы | `пока`, `для`, `в`, `цикл`/`погнали` |
| выход из цикла | `прерви`, `стоп`, `тормози` |
| следующая итерация | `продолжи`, `дальше` |
| возврат | `верни`, `возврат` |
| логика | `и`, `или`, `не` |
| литералы | `истина`/`правда`, `ложь`, `пусто`/`ничто` |
| импорт | `подключить`, `импорт`, `как` |

## 2. Типы

`пусто`, `логическое`, `целое` (int64), `дробное` (double), `строка` (байты +
UTF-8-корректные операции), `массив`, `словарь` (порядок вставки
сохраняется), `функция` (замыкание), `встроенная`, нативные объекты
(`Сервер`, `Соединение`, `Датаграм`, `Файл`).

* Истинность: `пусто` и `ложь` — ложь, всё остальное — истина.
* `==`/`!=` — для любых типов (числа int/float сравниваются численно).
* `< > <= >=` — числа и строки.
* `+` — числа, конкатенация строк (если хотя бы один операнд строка),
  конкатенация массивов.
* `/` на двух целых даёт целое только при точном делении, иначе дробное.
* Индексация: `a[i]` (целое, отрицательный — с конца; `a[len] = x` добавляет),
  `s[i]` — символ по кодовой точке, `m["ключ"]`.
  `длина(x)` — строка/массив/словарь.

## 3. Область видимости и замыкания

* Верхний уровень модуля — глобалы модуля. `пускай` в блоке — локаль.
* Блок `{ }` вводит область; локалы умирают в конце блока.
* Замыкания захватывают upvalue; `для (x в ...)` даёт **свежую** привязку
  переменной на каждой итерации; классический `для (init; cond; step)` —
  одну общую (как в C).
* Рекурсия поддерживается (глобалы и локальные `дело`).

## 4. Функции и методы

* Параметры со значениями по умолчанию: `дело f(a, b = 10)`.
  Переданный явно `пусто` тоже заменяется дефолтом (документированная особенность).
* Вызов методом `obj.имя(args)`:
  * для нативных объектов (`Сервер`, `Соединение`, …) вызывается метод класса,
    объект передаётся как self;
  * для словаря берётся поле; если это функция, принимающая первый параметр
    «под self» (arity == число аргументов + 1), словарь передаётся первым
    аргументом; если arity совпадает с числом аргументов — вызывается как
    обычная функция модуля (удобно для пространств имён).
* Ошибка времени выполнения печатает сообщение и стектрейс
  («строка N, <дело> (модуль …)»).

## 5. Модули

`подключить "имя"` / `"путь.goida"` [`как` алиас].

1. Уже загруженный модуль — возвращается его пространство имён.
2. Встроенные: `стандарт/std`, `математика/math`, `строки/strings`,
   `массивы/arrays`, `файлы/files`, `время/time`, `система/system`,
   `случай/random`, `сокеты/sockets`.
3. Файл `.goida`: каталог скрипта → `.` → каталоги `$GOIDA_PATH`.
   Выполняется один раз, результат кешируется; пространство имён — глобалы
   модуля (включая «скрытые» с `_` — соглашение, а не механизм).

Без `как` имя берётся из базы файла без `.goida` либо из имени встроенного
модуля.

## 6. ВМ и сборка мусора

* Компилятор: AST → байткод стековой ВМ (см. `src/opcode.h`).
* GC: mark-&-sweep, корни — стек ВМ, кадры, открытые upvalue, глобалы
  модулей, пулы констант, активные компиляторы. Финализаторы нативных
  объектов закрывают сокеты/файлы.
* Лимиты: стек ВМ 8192 значений, 512 кадров, 256 локалов на функцию.

## 7. REPL

Без аргументов `./goida` — REPL: глобалы живут между строками, одиночное
выражение печатает значение (кроме `пусто`), многострочный ввод по балансу
скобок, ошибки не завершают сессию.

## 8. Что НЕ гарантировано в 0.1

* Нет классов/наследования, исключений try/catch, строк-шаблонов `{...}`,
  потоков, чисел произвольной точности. Это в `ROADMAP.md`.
