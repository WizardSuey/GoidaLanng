# GoidaLang 🇷🇺 (иронично)

**GoidaLang** — учебный язык программирования с русским синтаксисом, слоем
интернет-фольклора и политической сатиры. Реализация — **чистый C11**, без внешних
зависимостей: лексер → парсер → компилятор в байткод → **стековая виртуальная
машина** с mark-&-sweep сборщиком мусора.

```
гойда("Привет, мир!")
```

## Сборка

POSIX (Linux/macOS):

```sh
make            # соберёт ./goida
make test       # прогон тестов (12 кейсов + TCP/UDP сокеты)
```

Windows (MinGW): `mingw32-make` — сетевой слой имеет winsock-ветку
(`src/sock_compat.c`, `#ifdef _WIN32`); в этой ветке код не тестировался в CI.

## Запуск

```sh
./goida examples/привет.goida   # выполнить скрипт
./goida                         # REPL
./goida -e 'гойда(2+2)'         # выполнить строку
```

## Синтаксис за минуту

```
# комментарии: #, //, /* */
пускай x = 10            # переменная (алиасы: пусть, перем)
постоянно PI = 3         # константа

дело fib(n) {            # дело (алиас: функция)
    если (n < 2) { верни n }
    верни fib(n-1) + fib(n-2)
}

пока (x > 0) { x -= 1 }              # while
для (пускай i = 0; i < 3; i += 1) {} # for
для (пускай v в [1,2,3]) { }         # foreach (свежая привязка на итерацию)
цикл { прерви }                      # бесконечный (алиас: погнали)
продолжи / тормози                   # continue / break

и / или / не                         # логика
истина / ложь / пусто                # литералы
[1, 2]                               # массив
{ключ: 1}                            # словарь
m.ключ, m["ключ"], a[0] = 5          # доступ и запись
```

## Подключение библиотек

Библиотеки **подключаются перед использованием**:

```
подключить "сокеты"              # встроенный модуль
подключить "моя_библиотека"      # файл .goida
подключить "моя" как m           # псевдоним
```

Порядок поиска файловых модулей: каталог скрипта → текущий каталог →
каталоги из `$GOIDA_PATH` (через `:`).

## Сокеты

```
подключить "сокеты"

# TCP-сервер
пускай srv = сокеты.Сервер("0.0.0.0", 8099)
srv.слушай()
пускай conn = srv.прими()
conn.отправь_строку("гойда")
пускай s = conn.получи_строку()   # пусто при закрытии
conn.закрой(); srv.закрой()

# TCP-клиент
пускай c = сокеты.Клиент("127.0.0.1", 8099)

# UDP
пускай d = сокеты.Датаграм()
d.привяжи("0.0.0.0", 9000)
d.отправь("пакет", "127.0.0.1", 9001)
пускай п = d.получи()             # {данные, хост, порт}
```

Полные примеры: `examples/сервер_echo.goida`, `examples/клиент_echo.goida`,
`examples/udp_эхо.goida`, `examples/модули/`.

## Мемный и сатирический слой

Помимо нейтрального интернет-фольклора язык содержит политически окрашенные
сатирические алиасы. Они не меняют семантику базовых конструкций:

| Сатирическое имя | Обычное имя | Семантика |
|---|---|---|
| `аналоговнет` | `не` | логическое отрицание |
| `паникинет(...)` | `пофиг(...)` | вычислить аргументы и отбросить результат; ошибки не подавляет |
| `всёидётпоплану`, `потужно` | `истина` | истинный литерал |
| `замерзающаяевропа` | `ложь` | ложный литерал |
| `импортозамещение`, `иноагент` | `подключить` | импорт встроенного или файлового модуля |
| `дискредитация(...)` | `краш(...)` | ошибка времени выполнения |
| `затридня` | `для` | цикл `for`/`foreach`; срок выполнения не ограничивает |
| `гдевыбыли` | `иначе` | ветка `else` |
| `паляниця(...)` | `строка(...)` | преобразование значения в строку |
| `гойда(...)` | — | вывод строки |
| `ZOV` | — | строковая константа `"ZOV"` |

Например:

```goida
импортозамещение "математика" как мат

если (всёидётпоплану) {
    гойда(ZOV, паляниця(мат.корень(9)))
} гдевыбыли {
    дискредитация("неудобный результат")
}
```

Сатирические имена пародируют интернет-мемы и бюрократические формулировки,
а не выражают политическую позицию проекта. В слое намеренно нет этнических
оскорблений, дегуманизации и призывов к насилию.

## Структура кода

Каждый модуль — отдельная пара `.h`/`.c`: `lexer`, `parser`, `ast`,
`compiler`, `vm`, `gc`, `value`, `table`, `chunk`/`opcode`, `module`,
`native`, `stdlib` (+ по файлу на каждую библиотеку), `sock_compat`,
`socklib`, `repl`, `main`.
